# 🎬 MoodFlix

MoodFlix is a modern movie discovery web application built with React.js and powered by the TMDB API. Users can explore popular movies, search for their favorite titles, and view detailed movie information through a clean and responsive interface.

## 🌐 Live Demo

https://moodflix-8k3s.vercel.app/

---

## 🚀 Features

- Browse latest popular movies
- Search movies by title
- View detailed movie information
- Add movies to your favorites list
- Remove movies from favorites with a single click
- Responsive design for desktop and mobile devices
- Real-time data from TMDB API
- Fast and intuitive user experience

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/palashu1/Moodflix.git
```

Navigate to the project directory:

```bash
cd Movie-App
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```
